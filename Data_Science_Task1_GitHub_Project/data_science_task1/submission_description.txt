This project presents a practical implementation of the Data Science Fundamentals Assessment using the Breast Cancer Wisconsin (Diagnostic) dataset available through scikit-learn. The main objective was to apply Python, Pandas, NumPy, statistics, data cleaning and exploratory data analysis techniques to a real-world dataset and generate meaningful insights.

The project begins with dataset understanding, including the number of observations, features, target variable, data types and real-world context. Data quality checks were performed to identify missing values, duplicate records and potential inconsistencies. The dataset did not contain missing values, so no imputation was required. Statistical analysis was then carried out using mean, median, mode, standard deviation and variance to understand the distribution and variability of important numerical features.

Exploratory Data Analysis was performed using class-distribution charts, feature comparisons, scatter plots and correlation analysis. These visualizations helped identify differences between benign and malignant observations and relationships among diagnostic measurements. An IQR-based outlier analysis was also performed to identify potentially unusual observations without automatically removing legitimate data points.

The final report documents the methodology, data preparation, statistical analysis, visualizations, key insights and conclusions. The project demonstrates a complete beginner-to-intermediate data science workflow and can be extended in future work with feature engineering, machine learning classification and model evaluation. The analysis is educational and is not intended for medical diagnosis.
